## 1. 「改单 / 加单」那条模式条要更显眼

现在长这样（在 `配送开单台.html` 第 393~401 行附近）：

```
＋ 手动加一行    客户漏写的、电话里补的，直接加进这张单
现在是：改单   [切到「加单」→ 老行冻住]
```

老板原话：「这个地方……**你要把它做得再显眼一点**」。

**为什么要紧**（见 [[规矩总表 §五点七]] / `说明-规矩总表.md`）：
改单和加单是两回事，弄错了后果不一样 ——
- **改单**：每一行都能改，重存，单号不变
- **加单**：当下这些行**立刻冻住**，新的接在后面

人要是没注意到自己现在在哪个模式，改完发现老行冻着改不动，
或者以为在加单其实把原单改了。**这条现在只有一行灰字，太不起眼。**
