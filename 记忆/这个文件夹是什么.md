# 这个文件夹是什么

这是 **Claude 的长期记忆** 的一份副本 —— 从 8 月 4 日起，跟代码放在一起。

## 为什么要复制过来

原件在这儿：

```
C:\Users\李正\.claude\projects\c--Users----Desktop-----\memory\
```

那是个**隐藏的系统目录**，跟这个项目文件夹是两回事。重装系统、换电脑、
或者哪天清理 `.claude`，那 24 条记忆就全没了 —— 而代码好好的。

所以复制一份放这儿，将来备份项目文件夹就一起带走了。

## 怎么用

- **`MEMORY.md`** 是索引：一行一条，说清每条记忆讲什么
- 其余每个 `.md` 一条记忆，四类：
  - `user` 老板是谁、什么偏好
  - `feedback` 老板给过的工作方式上的指点（含为什么）
  - `project` 在做的事、目标、约束
  - `reference` 外部链接、单据、面板

## ⚠ 这是副本，不是原件

Claude 读写的是上面那个隐藏目录，**不是这里**。
这里的副本不会自动更新 —— 隔一阵手动同步一次：

```
xcopy "C:\Users\李正\.claude\projects\c--Users----Desktop-----\memory\*.md" ^
      "C:\Users\李正\Desktop\食品系统\记忆\" /Y
```

或者直接跟 Claude 说一句「把记忆同步到项目文件夹」。

## 跟 `说明-规矩总表.md` 的分工

| | 装什么 |
|---|---|
| **记忆**（这里） | 老板拍过的板、说过的原话、为什么这么定 —— **跨对话** |
| **`说明-规矩总表.md`** | 生意规矩的正式条文 —— 斤转板怎么算、备注算不算数、认错=0 |
| **代码注释** | 每条规矩落到哪一行、当初踩过什么坑 |

三份互相印证。哪份跟哪份对不上，**以老板最近说的那句为准**。
