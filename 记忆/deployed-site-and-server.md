**这个项目已经上线了，别再说「还没有域名」。** 2026-07-31 我犯过这个错——查项目文件夹没找到域名就断言没有，实际部署资料在**桌面\部署包**（不在 食品系统 文件夹里）。以后要确认是否上线，先看 `C:\Users\李正\Desktop\部署包\看这里-操作步骤.txt`。

- **域名** `choeyy88.com`（Namecheap，A 记录指向服务器）
- **服务器** Hostinger 印尼雅加达，网站根目录 `/var/www/kaidan`，Caddy + HTTPS 自动续期
- **网页有 HTTP Basic 密码保护**（账号 laowu），凭据在那个 txt 里，**别往 memory / 聊天里抄密码**
- 站点标题写的是「**老吴豆腐** · 开单台」，跟价格库里的「广东尝元」不是同一个抬头，需要时问用户以哪个为准
- ⚠ 服务器在印尼，延迟 ~150ms，用户已知，将来做 ERP 时一起换机器

**部署方式（纯静态 scp，没有后端）**：
- `桌面\部署包\2-上传网页.bat` —— 双击上传，源目录写死是 `%USERPROFILE%\Desktop\食品系统`
- 只传 6 个文件：`配送开单台.html`、`进销存.html`、`引擎-解析.js`、`对照-预置.js`、`数据-价格库.js`、`数据-常用规格.js`
- **`密钥-本机.js` 特意不传**（传上去等于公开密钥），所以线上要在页面里手填一次 API 密钥
- 上传后把 `配送开单台.html` 软链成 `index.html`

**所以：改完本地文件 ≠ 线上更新。** 必须让用户双击 `2-上传网页.bat`，线上才会变。我没有服务器密码，传不了，只能提醒他去传。
