2026-07-31 拍板：界面用「**夜台**」方向 —— 深蓝墨底 `#15181D`、卡片 `#1D2127`、主色台灯琥珀 `#E8A33D`（琥珀底上的字用深色 `#15181D`，白字看不清）、绿色只表示「已就绪」。签名元素是顶部台灯光晕 + 金额合计的琥珀发光数字。销售单预览保持纸白 + 仿宋，提醒它最后要打印。**不做浅色/自动切换**，就一套深色。

同时定的「简约」原则：去掉教程横幅、示例按钮、大段说明文档；图片区收成一条；四步并成三步（客户与下单表 / 核对 / 销售单）；导出按钮只留打印、存入进销存、新开一单为主，Excel/图片/CSV 降为小号次要按钮。

**Why:** 他明确说「可以直接使用，不需要的不要放进去」。夜台是从「一晚上分几次收单」这个真实场景来的，不是纯审美选择。

**How to apply:**
- 两个页面 [配送开单台.html](配送开单台.html) 和 [进销存.html](进销存.html) **共用同一套配色**，进销存整套走 CSS 变量，换皮只动 `:root` 那一块 + 几处写死的 `#fff`。
- 改开单台的 HTML 结构前先跑一遍 id 校验：JS 里有 **85 个 `$("...")` 引用**，少一个整个初始化就抛错、全页哑掉。校验脚本思路是把 `$\("([^"]+)"\)` 全抓出来跟页面里的 `id="..."` 比对。
- 坑：核对表格里的数量框 `<input class="qty">` **没写 type**，所以 `input[type="text"]` 选不中它。要用 `input:not([type="file"])`。
- 改版前的原样留在 `配送开单台.备份-改版前.html`；5 个方案的对比页留在 `UI改版-5个方案.html`。
- 无头浏览器截图验证时，进销存会因为 file:// 下 IndexedDB 不回调而整页空白 —— 那是无头的问题不是代码问题，把 `indexedDB` stub 掉逼它走 localStorage 就正常了。
